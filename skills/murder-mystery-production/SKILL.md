# 머더미스터리 인쇄물 제작


작품과 확정된 규칙 버전을 확인한 뒤 [제작 지침](references/production.md)을 읽는다. 아래 수량과 규격은 정권 살인사건 제작본에 해당한다. 다른 작품에는 그 작품의 확정 수량과 인쇄 설계를 사용한다.

## 배포 구성

- 일반 카드 36장과 비밀 카드 3장: 앞면 39개와 뒷면 39개를 ID로 대응시킨다.
- 비밀 룰북 8종: 7인 배역에 여당원 각성 전·후가 별도다. 공개 앞면은 7종이다.
- 공용 설명서, 배역별 개별 PDF, 공개 앞면 합본, 제작자용 전체 합본을 구분한다. 전체 비밀 룰북 합본을 플레이어 공용 자료로 배포하지 않는다.
- 신자유 기사 판정표는 별도 밀봉 배포물이다. 기자회견 시작 때 제공하며 감점 수치를 다른 룰북에 노출하지 않는다.

## 이미지와 조판

증거 이미지는 실제 종이·물건을 촬영한 듯한 차분한 사진 스타일로 만든다. 긴 한국어 문장과 정확한 카드 제목은 이미지 생성에 맡기지 않고 조판에서 넣는다. 원본 증거 이미지와 카드 앞뒷면 완성물을 분리한다. 상세 방향은 [이미지 기록](references/evidence-images.md)을 참고한다.

## 인쇄 및 확인

- 카드: A4 한 장에 4장, 앞면 다음에 대응 뒷면, 긴 변 넘김 양면 인쇄. 뒷면은 앞면 위치에 맞춰 좌우 반전 배치한다. 텍스트 자체를 거울처럼 반전하지 않는다.
- 공용 설명서: A4 가로에 2쪽. 캐릭터 룰북: A4 세로.
- PDF를 렌더링하여 한국어 글꼴, 본문 잘림, 카드 ID, 앞뒷면 대응, 공개·비공개 정보 혼입을 확인한다. 장수와 파일 수를 확정 목록과 대조한다.
- 기존 PDF·문서 제작 도구가 있으면 사용하되 특정 도구가 없다는 이유로 규칙을 누락하지 않는다. 이 스킬은 규약 패키지이며 원본 이미지·PDF·폰트를 포함하지 않는다.
