# 증거 이미지 생성 기록

## 생성 방식

- OpenAI 내장 이미지 생성 도구 사용
- 기존 신자유 소지품 이미지 3장과 선행 제작 이미지 2장은 같은 프로젝트 원본을 재사용
- 카드 제목과 정확한 한국어 설명은 생성 이미지가 아니라 카드 조판 단계에서 별도 합성

## 공통 프롬프트 방향

`Photorealistic top-down Korean political murder-mystery evidence photograph, realistic paper and physical objects, restrained cinematic lighting, cool desaturated tones, no hands, no people unless the evidence itself is a photograph, no logo, no decorative card border, no readable long text because Korean titles and descriptions will be overlaid later.`

## 세부 세트

- 정치 문서: 비밀 합의서, 송금·법인·인사·정치자금·재심·사찰·안전 문서를 실제 수사 증거처럼 촬영
- 개인 소지품: 사진, 출입증, 프레젠터, 배터리, 송신기, 리모컨과 감지기를 각각 별도 증거 사진으로 제작
- 장소 증거: 와인잔, 파손 가방, 폭발 구조 분석도, 보안 구역도와 경호 배치표를 현장감 있는 수사 자료로 제작
- 비밀 분석: 손상된 생체 패치와 47.130 GHz 분석 그래프, 독성학 부검 자료와 13:20–13:40 표본 비교, 폭발 수신 장치 복원 자료를 제작
