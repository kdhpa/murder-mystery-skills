# 정권 살인사건 제작본

## 완성 구성

- 기본 필드 카드 36장
  - 인물 소지품 21장
  - 장소 증거 15장
- 비밀 카드 3장
- 카드 앞면 PNG 39개 / 뒷면 PNG 39개
- 캐릭터 비밀 룰북 8종
  - 신자유
  - 정민주
  - 나국힌
  - 정의준
  - 나경호 / 이루민
  - 여당원 각성 전
  - 여당원 각성 후
  - 고원직
- 공용 게임 설명서
- 캐릭터 공개 앞면 7종 PNG 및 합본 PDF
- 신자유 전용 기사 판정표

## 인쇄 방법

- `인쇄용/정권_살인사건_전체_카드_인쇄용.pdf`
  - A4 한 장에 카드 4장 배치
  - 앞면 다음에 같은 장의 뒷면이 이어짐
  - 양면 인쇄 시 긴 변 넘김
  - 뒷면은 앞면 위치에 맞도록 좌우 반전 배치됨
- `인쇄용/정권_살인사건_게임_설명서.pdf`
  - A4 가로, 한 면에 설명서 2쪽
- `인쇄용/정권_살인사건_캐릭터_룰북_전체.pdf`
  - A4 세로, 공개 앞면과 비공개 본문을 포함한 캐릭터 룰북 전체 합본
- `인쇄용/정권_살인사건_캐릭터_공개_앞면_전체.pdf`
  - 배역 배정 전 또는 게임 시작 시 공개할 수 있는 앞면만 모은 합본
- `캐릭터 룰북/`
  - 배역별 개별 배포용 PDF
- `캐릭터 공개 앞면/`
  - 배역별 공개 앞면 PNG
- `인쇄용/정권_살인사건_신자유_기사_판정표.pdf`
  - 기자회견 시작 때 신자유에게만 개봉해 주는 별도 판정표
  - 기사 감점 수치는 캐릭터 룰북과 공용 게임 설명서에 들어 있지 않음
