# 머더미스터리 제작·정합성


[제작 규약 원문](references/authoring-conventions.md)을 읽는다. 작품의 기존 파일 구조를 먼저 확인하고 실제 경로를 사용한다. 원문의 `/mystery/bible`, `/player-facing`, `/gm-guide`는 역할 구분 예시이며 기존 폴더를 강제로 재구성하지 않는다.

## 수정 원칙

- 단서·타임라인·캐릭터 중 하나를 수정하면 나머지 둘도 함께 확인한다. 새 요소를 쓰기 전에 기존 설정과 충돌하는 부분을 먼저 알린다.
- 범인, 사인, 동기, 시간, 승리 조건처럼 결과를 바꾸는 불확실한 사실은 임의 확정하지 않는다. 충돌하는 출처를 제시하고 필요한 선택만 사용자에게 묻는다. 영향을 받지 않는 작업은 진행한다.
- 캐릭터 추가 시 관계·목격·알리바이·목표와 조사 인원 및 카드 총량 영향을 확인한다. 타임라인 변경 시 직접 목격, 전해 들은 정보, 거짓 진술을 구분한다.
- 제작자용 진실과 인물이 알고 있는 사실을 구분한다. 용의자의 살해 의도·미수와 실제 사망 원인을 혼동하지 않는다.

## 스포일러와 출력

- 진상이나 숨은 정체를 포함한 제작자 자료는 상단에 `[SPOILER]`를 표시한다.
- 플레이어용 시트 작성에는 공개·배역별 배포가 허용된 자료만 사용하고 `truth.md`를 직접 참조하지 않는다. 원문의 “bible은 참고용”은 비공개 진실을 배포물에 옮겨도 된다는 뜻으로 해석하지 않는다.
- 개인 비밀 시트는 해당 인물에게만 허용된 지식과 목표를 담는다. 공개 앞면과 비공개 본문을 분리한다.
- 변경 결과에는 수정한 파일, 함께 확인한 연관 자료, 남아 있는 충돌을 짧게 기록한다.

단서 전용 작업은 설치되어 있다면 `murder-mystery-clue-design`, 작품별 운영 규칙은 `murder-mystery-running`을 사용한다. 미설치 상태에서는 현재 프로젝트의 대응 원문을 직접 읽는다.
