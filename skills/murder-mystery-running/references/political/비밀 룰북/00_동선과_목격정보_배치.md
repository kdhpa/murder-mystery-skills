# 비밀 룰북 동선·목격정보 배치 원칙

이 문서는 필드 카드가 아니다. 각 인물의 비밀 룰북에 시간과 목격 정보를 나누어 넣기 위한 제작자용 설계표다.

## 기본 원칙

- 한 사람의 룰북만으로 전체 동선을 완성할 수 없게 한다.
- 각 인물은 자기 행동 1개와 다른 인물을 본 목격 정보 1개 이상을 가진다.
- 정확한 시간은 룰북에 적고, 장소 간 연결 관계는 경호실의 보안 구역도로 확인한다.
- 목격자는 얼굴을 본 경우와 `경호-01 배지 또는 경호복만 본 경우`를 구분한다.
- 일부 인물은 자신의 범행 시도와 관련된 시간을 거짓말하거나 숨길 수 있다.
- 모든 정보를 합치면 실제 나경호와 나경호로 위장한 이루민이 같은 시간대에 다른 장소에 있었다는 모순이 나타나야 한다.

## 최종적으로 조합되어야 하는 모순

1. 실제 나경호는 폭발 직전까지 대통령 가까이에 있었다.
2. 같은 시간대에 경호-01의 신분을 사용한 인물이 다른 보안구역에도 나타난다.
3. 폭발 뒤 실제 나경호가 대통령 근접 구역에서 빠져나왔다는 목격은 존재하지 않는다.
4. 그런데 폭발 뒤 나경호의 얼굴과 복장을 한 인물이 다른 대피 통로에서 생존자 대피를 지휘한다.
5. 신체 표식이나 배지 번호가 아니라 겹치는 목격 시각, 담당 임무와 장소 모순을 통해 두 사람이 존재했다는 결론에 도달한다.
6. 따라서 폭발 후의 나경호는 폭발 전 대통령 곁에 있던 실제 나경호와 같은 사람이 아니다.

정확한 시각, 목격자 배분과 거짓말 가능 범위는 전체 타임라인을 확정할 때 각 인물 비밀 룰북으로 옮긴다.
