| 사건 현장 | 대통령 전용 와인이 남은 잔 / 파손된 검은 가방 / 폭발 중심부 구조 분석도 | 0 |
| 경호실 | 경호 인력 식별·권한 대조표 / 광화문 행사 보안 구역도 / 광화문 행사 경호 임무 배치표 | 0 |

### 사건 현장 최종 구성

- 파손된 검은 가방 — 확정
- 대통령 전용 와인이 남은 잔 — 확정, SC-02 확인 카드
- 폭발 중심부 구조 분석도 — 확정, 무선 장치와 공개 조합 시 SC-03 확인 조건 성립

### 경호실 확정 구조

- 경호 인력 식별·권한 대조표
- 광화문 행사 보안 구역도
- 광화문 행사 경호 임무 배치표

정확한 시각과 인물별 동선은 카드가 아니라 각 인물의 비밀 룰북에 나누어 적는다.

## 별도 비밀 카드 — 3장 모두 지정 완료

1. 대통령 생체 패치 정밀 분석 결과 — 지정 완료
2. 대통령 부검 결과서 — 지정 완료
3. 폭발 수신 장치 복원 결과 — 지정 완료

## 현재 선거 판정 규칙

1. 최종 지지율이 가장 높은 후보가 당선된다.
2. 동률이면 감점 기사가 적은 후보가 당선된다.
3. 지지율과 감점 기사 수도 같은 정민주·나국힌 동률이면 나국힌이 우선한다.
4. 결선투표는 실시하지 않는다.
