# 정권 살인사건 — 신자유 전용 기사 판정표

기자회견 시작 때 처음 개봉한다. 신자유가 직접 확인했거나 사실대로 제보받은 증거 중 아래 조건을 충족한 기사는 선택 없이 전부 발표한다.

## 정민주

- JM컴퍼니 송금 지시 기록 + JM컴퍼니 실소유자 조사자료: 지지율 -1
- 비상 승계·국민통합정부 비밀 합의서: 지지율 -1
- 대통령 전용 와인이 남은 잔 + 해당 잔의 비밀 분석 내용: 지지율 -1

## 나국힌

- 나국힌 미신고 정치자금 기록: 지지율 -1
- 소방시설 컨트롤 리모컨 + 보안 구역도 + B-7 진입과 이탈을 잇는 두 목격: 지지율 -1

## 정의준

- 비공식 협조자 승인서: 지지율 -1

같은 기사는 여러 번 감점하지 않는다. 기사 발표 뒤에는 취소하거나 증거를 돌려줄 수 없다.
