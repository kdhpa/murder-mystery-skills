# 경호실 장소 카드

경호실에는 완성된 시간표나 인물별 동선 기록을 두지 않는다. 구체적인 시각과 목격 정보는 각 인물의 비밀 룰북에 나누어 적고, 경호실의 세 카드는 그 증언들을 서로 연결하고 검증하는 도구로 사용한다.

## HS-01 경호 인력 식별·권한 대조표 — 구성 확정

> 광화문 행사에 투입된 경호 인력의 이름, 호출번호, 생체 식별 코드와 접근 가능 구역을 연결한 내부 대조표다.

카드에 들어갈 핵심 정보:

- `나경호 경호실장 = 경호-01`
- 경호-01의 생체 식별 코드
- 경호-01이 대통령 근접 구역과 B-7 보안구역에 접근할 권한을 가졌다는 사실
- 경호-02와 경호-03은 비교용 정상 정보만 간략히 표시

기능:

- 비밀 룰북에 적힌 `경호-01을 보았다`라는 목격담이 누구를 뜻하는지 해석한다.
- 희생자 사진의 경호복 표식과 목격담 속 호출번호를 나경호와 연결한다.
- 시간과 실제 이동 경로는 이 카드에 적지 않는다.

## HS-02 광화문 행사 보안 구역도 — 구성 확정

> 중앙무대, 대통령 대기실, 의전 준비실, B-7 설비통로, 경호실과 생존자 대피 통로의 연결 관계를 표시한 내부 지도다.

카드에 들어갈 핵심 정보:

- B-7이 연단 하부와 대통령 퇴장 경로에 연결된다는 사실
- 대통령 대기실과 B-7 사이에는 보안 검문 구역이 있다는 사실
- 폭발 이후 사용된 생존자 대피 통로의 위치
- 각 구역이 서로 붙어 있는지, 별도 검문을 거쳐야 하는지만 표시

기능:

- 플레이어들이 각자 알고 있는 목격 장소를 지도 위에서 연결한다.
- 같은 시간대에 서로 떨어진 장소에서 나경호가 목격되었다면 두 사람이 존재했다는 의심을 만든다.
- 나국힌의 B-7 질소 설비 계획과 실제 폭탄 설치 경로를 함께 검토하게 한다.
- 정확한 이동 시간이나 특정 인물의 동선은 카드에 적지 않는다.

## HS-03 광화문 행사 경호 임무 배치표 — 구성 확정

> 광화문 행사 동안 각 경호 인력이 맡아야 할 역할과 담당 구역을 정리한 사전 임무 배치표다. 실제 이동 기록이나 출입 시각은 적혀 있지 않다.

카드에 들어갈 핵심 정보:

- 나경호는 대통령 근접 경호 책임자로 배정되어 연설 종료 전까지 대통령 곁을 이탈할 수 없다.
- 경호-02는 무대 외곽, 경호-03은 대피 통로를 담당한다.
- B-7 점검과 설비 관리는 별도 시설팀 담당이며 나경호의 예정 임무가 아니다.
- 비상상황 발생 뒤에는 나경호가 생존자 대피 지휘를 맡도록 규정되어 있다.

기능:

- 대통령 곁과 다른 보안구역에서 같은 시간대에 나경호가 목격되면 예정 임무와 맞지 않는다는 사실을 드러낸다.
- 폭발 직전 대통령 곁의 목격담과 폭발 후 에스코트 목격담을 조합하면 실제 나경호의 사망과 가짜 나경호의 활동을 추리하게 한다.
- 카드 자체에는 나경호의 실제 이동 시각이나 위장 인물의 정체가 적혀 있지 않다.

## 카드에서 제외하고 비밀 룰북으로 옮길 정보

- 인물별 정확한 도착·이탈 시각
- 나경호 또는 경호-01을 목격한 시간과 장소
- 나국힌이 B-7에 들어간 정확한 시각
- 대통령 전용 축하주가 보관함에서 반출·반입된 시각
- 폭발 전후 각 후보의 위치
- 폭발 후 나경호가 생존자를 에스코트한 순서

## 다른 장소로 이동한 정보

- 실제 폭발 장치의 원격 수신 흔적은 `사건 현장`의 수신기 파편 후보로 관리한다.
- 대통령 전용 와인이 남은 잔은 `사건 현장`에서 관리한다.
- 경호실 카드만으로 대통령의 직접적인 사인이나 이루민의 이름을 밝히지 않는다.
- 배지 일련번호나 동일 번호 중복 기록은 사용하지 않는다.
