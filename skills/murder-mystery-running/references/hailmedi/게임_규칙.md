## 감염 혈액 색 진행

외계 바이러스에 감염되면 혈액 색이 단계적으로 변한다.

| 단계 | 혈액 색 | 상태 |
|---|---|---|
| 1단계 | 빨강 (정상) | 미감염 |
| 2단계 | **보라** | 감염 진행 중 (생존) |
| 3단계 | **파랑** | 사망 |

> **게임 내 물증**: 박진균 소지품 A-1(보라빛 액체가 묻은 휴지) → 감염 진행 중 증거.  
> 선장 사망 시 혈액은 파란색. 이소아가 22:30에 목격한 피는 보라빛(사망 직전 단계).  
> 플레이어들은 파란 피/보라 피의 의미를 모른다. 추리 요소.

## 공통 배경 — 함선 내 정신 건강

> 헤일메디호 승무원들은 모두 함선에 **아주 오랫동안** 탑승해 있었습니다.  
> 격리된 우주 환경, 단절된 외부와의 소통으로 정신 건강이 온전하지 않습니다.  
> 나우성B의 도플갱어 주장이 정신병으로 취급받는 이유이기도 합니다.  
> GM은 이 배경을 통해 모든 증언의 신뢰도가 완전하지 않음을 암시할 수 있습니다.

## 게임 메카닉

### 나우성A 탈출 메카닉

- **조건**: 소지품 B-2(긴급 탈출 코드)를 소지하고 있어야 탈출 행동 가능
- **차단 방법**: B-2 카드를 빼앗으면 탈출 불가
- **성공 시**: 나우성A 탈출 성공 엔딩

---

## 행동 단계 순서

| 순서 | 인물 | 행동 |
|---|---|---|
| 1 | 재키 핀 | 훔치기 — 조건 없이 누군가의 카드를 강제로 1개 빼앗는다 |
| 2 | 박진균 | 치료제 사용 — 치료제 카드 소지 시 스스로에게 투여하여 감염 치료 |
| 3 | 나우성B | 정체 질문 — 승무원 1명에게 "저의 정체는?" 강제 답변 요구 |
| 4 | 나우성A | 탈출 시도 (B-2 소지 시 성공) |
| 5 | 박소냐 | 정보 전달 — 외계 신호 좌표 카드 소지 시 러시아 본부로 전송 성공 |
| 마지막 | 수갑 소지자 | 1명 구속 (범죄자+죄명 정확히 지목 시 +1점) |

## 핵심 카드 연결 구조

### 나우성A 정체 증명 체인

```
함교-2 (탑승 기록)
  → 나우성 이름이 두 번 등장
      +
B-1 (위조 탑승 배지) vs D-1 (진짜 신분증)
  → 두 카드 비교 시 위조 확인
      +
히든-2 (외계어 메모) + G-1 (정체 불명 바이알)
  → 외계인 존재 확정
```

### 이소아 범죄 증거 체인

```
의료-1 (처방 기록) — 처방량 이상
      +
의료-2 (선장 의료 기록) — 혈액 변색 기재
      ↓
독성 과다 투여 가능성 → 그러나 사인 확정 불가
(바이러스 감염 사망인지 독살인지 끝까지 불명확)
```

### A.R.I.A 학대 증거 체인

```
E-2 (시스템 경보 로그) — 삭제 구간 = 렌 박 행동 시각
      +
H-1 (AI 관리자 접근 카드) 렌 박 소지 사실
      ↓
렌 박의 기억 삭제 시도 정황 증거
```
