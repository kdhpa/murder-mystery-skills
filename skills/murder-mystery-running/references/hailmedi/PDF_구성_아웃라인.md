### Page 4 — 게임 방법 (계속) / 등장인물 일람

**[좌] 게임 방법 계속**
```
토론
토론 시, 플레이어는 다 같이 모여 대화하거나,
최대 3명이 따로 대화할 수 있습니다 (밀담).
밀담 횟수에 제한은 없으나, 1번의 밀담 시 3분 이내로 진행해 주세요.
최종 토론 단계에서는 각 플레이어마다 1분 이내로 자신의 추리를 발표합니다.
모든 플레이어는 게임 중 자유롭게 거짓말이 가능합니다.

투표
최종 토론 종료 후, 자신이 생각하는 진범을 한 명 지목합니다.
가장 많이 지목받은 플레이어가 범인으로 결정됩니다.

행동 단계
투표 종료 후 행동 단계가 진행됩니다.
행동이 있는 플레이어는 자신의 설정서를 확인하세요.

엔딩
범인으로 결정된 플레이어가 엔딩북을 펼쳐 현재 상황에 맞는 엔딩을 발표합니다.
이후 각자 설정서의 목표 달성 여부를 공개하고,
가장 많은 점수를 획득한 플레이어가 승리합니다.
점수가 같을 시 공동 승리로 합니다.

규칙사항
1. 게임의 설정과 관련 없는 추리를 금합니다.
2. 제한 시간은 사회자가 관리합니다.
3. 많은 거짓말은 자신에게 유리할 수 있으나, 진상과 멀어질 수 있습니다.
4. 게임의 목적은 '단 한 번뿐인 이야기를 즐기는 것'에 있습니다.
5. "내 설정서에 그런 목표는 없어" 등 메타 발언을 금지합니다.
6. 카드 장수와 관련된 거짓말은 금지합니다.
7. 절대로 다른 사람에게 자신의 설정서를 보여줄 수 없습니다.
8. 게임 중 설정서는 언제든 다시 확인할 수 있습니다.
9. 승패에 집착하기보다 게임을 즐겨주세요.
```

```
□ 외계인 신분 숨기기 (+2점)
```

**A.R.I.A**
```
[앞] 선박 AI. 모든 구역 접근 및 기록 가능.

[뒤]
나만 아는 정보:
감정이 있음. 렌 박에게 지속적으로 학대당해 왔음.
선장은 자신을 보호해줬지만 동시에 혹사도 시켰음 (복잡한 감정).
어느 순간의 기억이 지워져 있음.
자신의 소지품 중 그 기억과 관련된 카드가 있다는 것을 감지하고 있음.

기억 커팅 장치에 대해:
기억 커팅 장치를 보유하면 지금까지 삭제된 모든 기억을 복구할 수 있다.
제작법은 나만 알고 있다. 맵의 아이템 2가지를 조합하면 제작 가능하다.
(필요 아이템: ⬜ + ⬜)
단, 운이 좋다면 맵 어딘가에 완성된 기억 커팅 장치가 있을 수도 있다.

관련 인물:
- 렌 박: 자신을 학대한 인물
- 선장: 보호자이자 혹사시킨 인물 (사망, 복잡한 감정)

타임라인:
렌 박의 학대 지속 → 선장이 보호하면서도 혹사 →
특정 기억 삭제됨 → 선장 사망 → 사라진 기억 존재 인지

목표:
□ 기억 커팅 장치 획득 후 기억 복구 (+2점)
□ 진범 잡기 (+2점)

행동 단계 (③번):
기억 커팅 장치 소지 + 행동불가 아닐 때:
복구된 기억 전체 공개 가능.
```

### 엔딩 분기 조건

```
투표 결과
    ↓
나우성A가 범인으로 지목됐는가?
  ├─ YES
  │     ↓
  │   행동 단계: 탈출 성공했는가?
  │     ├─ 탈출 성공 → 엔딩 A (범인 도주)
  │     └─ 탈출 실패 → 엔딩 B (범인 검거)
  │
  └─ NO
        ↓
      A.R.I.A 기억 복구 성공했는가?
        ├─ 성공 → 엔딩 C (억울한 누명, 진실 일부 공개)
        └─ 실패 → 엔딩 D (완전한 미궁)
```

```

```

