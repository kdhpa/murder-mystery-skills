# 원문 충돌 및 적용 범위

원문을 임의 수정하지 않았다. 아래 판단은 스킬로 옮기는 과정의 분류이며 새로운 게임 규칙이 아니다.

| 항목 | 충돌 | 적용 방법 |
|---|---|---|
| 정권 조사 시작 순서 | 전체 구조 문서: 무작위 시작·시계 방향 / 새로운 룰: 고정 우선순위 | 이번 게임 진행이라고 명시한 새로운 룰을 기본으로 읽고 이전안과 차이를 표시 |
| 정권 GM 없는 버전 | 선택형 기사 보도 / 현재 진행의 전부 의무 보도 | GM 없는 메모는 이번 플레이 미적용이라고 명시되어 있으므로 미래안으로 보존 |
| 정권 소지품 수 | 전체 구조 문서 중 장수가 달라도 된다는 문구 / 같은 문서 확정 구성 12분류 각 3장 | 현 구성은 각 3장·36장. 변경 요청 시 조사 총량까지 재계산 |
| 정권 계몽 | GM 확인 없는 계몽 / 게임 전체 GM 운영 | 특정 절차의 자율 처리를 전체 게임의 GM 부재로 확대하지 않음 |
| 헤일메디호 카드 수 | 게임 규칙·카드 설계 26장 / 기획 정리 24+12 / PDF 아웃라인 40장 | 버전 미확정. 최종 룰북 전에 선택 필요 |
| 헤일메디호 행동 순서 | 게임 규칙 재키 핀부터 / 기획 정리 렌 박부터 / 인물별 본문과 요약도 다름 | 임의 통합 금지. 채택 순서와 개별 조건을 함께 확정 |
| 헤일메디호 혈액·사인 | 게임 규칙 22:30 보라빛·사인 불명확 / 카드 설계·기획 정리 파란 피·이미 사망 | 진범 추리 핵심이므로 반드시 버전 확인 |
| 헤일메디호 아이템 배치 | 기억 커팅 장치 렌 박 소지품 / 화물칸 필드 / 치료제 구역 카드 또는 이소아 소지품 | 카드 ID와 실제 배치본까지 대조 후 결정 |

원문의 빈칸·미정·임시안은 그대로 미확정이다. 특히 초안의 숫자와 기술 설정을 현실 세계의 의료·법률 사실로 일반화하지 않는다.
