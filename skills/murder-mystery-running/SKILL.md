# 머더미스터리 운영·판정


이 스킬에는 제작자용 원문과 스포일러가 포함된다. 플레이어 질문에는 허용된 단계·배역 정보만 답한다. 일반 머더미스터리 전체의 보편 규칙으로 적용하지 않는다.

먼저 [원문 색인](references/index.md)에서 작품과 필요한 문서를 선택하고, [버전 충돌 기록](references/conflicts.md)을 읽는다. 모든 원문을 한꺼번에 읽지 않는다. 현재 사용자의 명시적인 선택과 프로젝트의 이후 확정 사항이 이 스냅샷보다 우선한다.

## 정권 살인사건

기본 진행 순서는 `새로운 룰.md`를 기준으로 읽는다. 조사, 비밀 카드, 개별 행동은 해당 원문을 추가로 확인한다.

- 조사자는 신자유를 제외한 6명이다. 각 차수에 다른 분류 3곳을 조사하며 자기 소지품과 같은 차수의 중복 분류는 불가하다. 소진된 분류 재선택에는 횟수를 쓰지 않는다. 두 차수 사이에는 같은 분류를 다시 조사할 수 있다.
- 현재 진행 규칙의 획득 우선순위는 정민주 → 나국힌 → 정의준 → 고원직 → 여당원 → 나경호다. 옛 구조 문서의 무작위 시작과 섞지 않는다.
- 교환·양도·제보는 토론 중에 한다. 비밀 카드는 양도하지 않고 확인자가 공개 또는 제보한다. 조합 조건과 공동 확인 범위를 원문대로 유지한다.
- 2차 토론 뒤 행동 전에 범인 답안을 공개 인물명으로 제출하고 고정한다. 간첩 선택과 범인 답안은 별도다.
- 행동은 정민주 → 정의준 → 나경호 → 나국힌 → 살아 있는 고원직·각성 여당원 → 신자유 순서다. 살해 이후 도주 가능 여부와 실제 기사 사용에 따른 점수를 확인한다.
- 기자회견 시작 때 별도 판정표를 신자유에게 지급한다. 충족된 기사는 전부 의무 보도하며 국가기밀 지정 카드는 기사 근거에서 제외한다. 기사 감점 수치는 공용 설명서나 캐릭터 룰북으로 옮기지 않는다.
- 지지율은 항상 5/5/4에서 시작한다. 각성으로 토큰을 이동하지 않는다. 기사 감점 후 동률은 핵심 스캔들 수, 완전 동률 예외를 원문대로 적용하며 결선투표를 만들지 않는다.
- 계몽은 차수당 한 명, 이월 불가, 동일 대상 반복 불가다. 각성 및 확인 암구호는 해당 비밀 룰북을 읽어 처리한다. 이 부분은 GM 확인 없이 진행되지만 게임 전체가 GM 없는 버전이라는 뜻은 아니다.
- `GM 없는 버전 메모.md`는 미래 검토안이다. 선택 보도·거래 기능을 현재 진행에 넣지 않는다.

정확한 목표·점수는 배역별 비밀 룰북, 기사 조합·감점은 별도 판정표, 비밀 카드 조건은 비밀 카드 구조 문서에서 읽는다. 배역 이름과 카드 ID를 추정으로 바꾸지 않는다.

## 헤일메디호

`게임_규칙.md`와 `카드_설계.md`의 26장 구성, `기획_정리.md`와 PDF 아웃라인의 다른 구성·행동 순서가 충돌한다. 최신 버전을 파일명이나 수정 시각만으로 확정하지 않는다. 요청이 판정이나 최종 배포에 영향을 주면 사용자가 채택할 규칙 세트를 확인한다. 확정 전에는 버전별 차이를 설명하고 초안임을 표시한다.

## 판정 결과

판정에는 적용 버전, 충족된 조건, 처리 순서, 결과 및 점수의 근거 파일을 짧게 제시한다. 기록에 없는 소유권·공개 상태·사망 상태는 지어내지 않는다. 제공된 플레이 상태로 판정할 수 없는 부분만 질문한다.
