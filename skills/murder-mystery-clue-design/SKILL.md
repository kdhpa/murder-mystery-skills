# 머더미스터리 단서·카드 설계


카드의 작품·규칙 버전·대상 독자를 먼저 확인한다. 해당 작품의 원문을 읽고 카드 ID를 유지한다. 아래 원칙 중 정권 살인사건의 규칙은 다른 작품에 자동 적용하지 않는다.

## 단서 작성

제작자용 설계 단계에서는 진상을 확인해 단서·캐릭터·타임라인의 모순을 검사한다. 플레이어에게 보이는 본문에는 발견 가능한 정보만 적고 정답이나 연결 해설을 넣지 않는다. 원래 제작 규약의 공통 형식은 다음과 같다.

```text
[단서명] / 발견 위치 / 공개 시점
내용:
연결 단서:
```

연결 단서 항목은 설계본에서 관리하고, 배포본에는 해당 시점에 공개해도 되는 연결만 남긴다. ID, 장수, 소유·획득 조건, 공개 조건, 효과는 기존 카드 양식에 맞춰 별도 관리한다.

## 정권 살인사건의 설계 원칙

- 기본 필드 36장(인물 소지품 7종 × 3장 + 장소 5종 × 3장)과 비밀 3장을 분리한다. 6명 × 3장 × 2회 = 36장으로 조사 종료 시 필드가 소진된다.
- 핵심 카드를 누군가 숨겨도 추리할 수 있도록 진범에 이르는 조합 경로를 두 개 이상 마련한다.
- 한 인물의 룰북만으로 전체 동선을 완성하지 않는다. 자기 행동과 다른 인물 목격을 각각 하나 이상 배치한다. 시간은 개인 룰북에, 장소 연결은 구역도에 둔다.
- 얼굴을 직접 본 목격과 배지·복장만 본 목격을 구분한다. 정체 추론이 시간·임무·장소의 모순으로 성립하는지 확인한다.
- 비밀 카드의 획득자, 조합 참여자, 내용을 아는 사람, 기자 제보 여부는 서로 다른 상태다. 양도 금지와 내용 공개 허용을 함께 유지한다.
- 기술 규격만으로 정답을 식별하도록 설계하지 않는다. SC-03은 송신기 식별이 아니라 시간·동선 조합에 쓰는 카드다.

작품 세부 규칙과 원문은 설치된 `murder-mystery-running`의 자료 색인 또는 프로젝트의 카드 구조·비밀 카드·목격 배치 문서에서 읽는다. 검토 결과에는 실제 카드 총량, 열리는 비밀 카드, 막힌 추리 경로와 수정 영향을 제시한다.
