# 머더미스터리 제작·운영 스킬

로컬에 정리된 머더미스터리 제작 규약과 정권 살인사건·헤일메디호의 운영 규칙을 옮긴 스킬 4종입니다. 제작자용 진상과 개인 비밀을 포함합니다.

| 스킬 | 역할 |
|---|---|
| murder-mystery-authoring | 제작 규약, 캐릭터·타임라인·진상 정합성, 스포일러 분리 |
| murder-mystery-clue-design | 단서, 목격, 카드 수량·공개 조건, 추리 경로 |
| murder-mystery-running | 작품별 조사·행동·점수·기사 판정, 버전 분리 |
| murder-mystery-production | 카드·룰북·공개 앞면·인쇄 조판과 배포 |

## 설치와 사용

`skills/` 안의 네 폴더를 사용하는 에이전트의 스킬 디렉터리에 복사합니다. Codex 개인 설치 위치는 `~/.codex/skills/`입니다. 네 폴더를 함께 설치하면 작품별 원문 참조까지 사용할 수 있습니다.

예: `$murder-mystery-authoring 캐릭터 변경이 단서와 시간표에 미치는 영향을 검토해줘.`

예: `$murder-mystery-running 정권 살인사건의 행동 페이즈와 기사 판정을 확인해줘.`

## 원문 범위

- 다운로드 머더 미스터리의 `Claude.md` 제작 규약: 실제 형식은 DOCX이므로 텍스트 추출.
- 같은 폴더의 `기획/` Markdown 전체: 헤일메디호의 규칙, 카드, 타임라인, 인물, PDF 아웃라인.
- 정권 살인사건의 루트 기획 문서, 비밀 룰북, 비밀 카드, 파생 카드, 장소 카드, 기사 판정표.
- 제작본 README와 이미지 생성 기록.

운영 자료의 개별 색인은 `skills/murder-mystery-running/references/index.md`, 원문 대조용 해시는 `sources.json`에 있습니다. 서로 다른 작품은 섞지 않았고 원문 충돌은 `references/conflicts.md`에 기록했습니다. 이미지·PDF 결과물, 웹사이트 코드와 타인의 샘플 룰북은 규약 패키지에 포함하지 않습니다.

원본 파일은 수정하지 않았습니다. 현재 프로젝트에서 이후 확정한 규칙이 이 스냅샷보다 우선합니다.
